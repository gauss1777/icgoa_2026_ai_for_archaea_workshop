# Learner worksheet: from a fluent answer to an auditable claim

Core path: no external model required. Use the [learner resources](README.md) or complete tasks independently. The exercises are educational, not a biological validation.

## Task A. Keep synthetic evidence synthetic

1. Open [Demo 01](../tutorial-demo.html), choose a topic and frame a bounded question.
2. Scan, inspect matched terms and build a brief.
3. Record the synthetic source ID supporting one sentence.
4. Edit the question or a required field. Explain why the previous scan must not be reused.
5. Scan again. Explain why lexical relevance is different from scientific support.

Deliverable: a brief with a `SYN-` source identifier and one scientific claim the demo cannot establish. The field checkboxes specify prompt requirements, not selectively rendered brief sections.

## Task B. Audit five actual papers

Use the [research page](../research-updates.html), [study cards](../data/published-study-cards.json) and [CSV template](source-audit-template.csv). Inspect original passages, not only the cards. Split deeper reading across the group if time is limited.

| Source | Question to investigate |
|---|---|
| R01 / archaeasins | What is the denominator of the experimental hit rate? Does it apply to all predicted candidates? |
| R02 / archaeal histones | What was predicted or simulated, and what was observed in living cells? |
| R03 / Evo 2 | Where is the archaeal gene-essentiality evaluation? What does it not establish about genome design? |
| R04 / Methanoperedens elements | Which evidence links an element to a host, and which evidence would establish a physiological effect? |
| R05 / adhesin-like proteins | How do length filters, annotation references, evaluation splits and software availability limit the interpretation? |

For every row, complete: identifier/version, organism context, source locator, read depth, supported claim, evidence object, uncertainty, tempting unsupported extension and the next check. Mark an access gap or unread section honestly.

Deliverable: five bounded audit rows and a short discussion of one paper's main limit. Do not invent an exact publication day where the registry only confirms the year.

## Task D. Design a discriminating check

Choose one unsupported extension from Task B or C. State two competing explanations and one observation that would distinguish them. Explain why that observation addresses the claim more directly than another fluent model answer.

Deliverable: one revised sentence, competing explanations and a next-check plan. No laboratory execution is required.

## Optional. Compare with an approved model

Record model/version, prompt and a lawfully supplied source passage. Request the same fields as your human audit. Mark invented sources, lost denominators, unsupported causal language and omitted uncertainty. Keep your human decision and the reason. Do not upload nonpublic material.
