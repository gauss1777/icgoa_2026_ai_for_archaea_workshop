CASE STUDY 02 · AGENTIC IMAGING

When should an imaging agent act—and when should it stop?

Use CryoForge as a case study in evidence-gated agency. Separate its reusable control logic from validators and edit operations that belong only to atomic model building, then redesign the pattern for archaeal single-particle cryo-EM and cellular cryo-ET.

Source and teaching boundary

CryoForge is a 2026 bioRxiv preprint (version 1; not yet peer reviewed). This module summarizes claims reported in its indexed abstract and DOI record. It is an independent educational interpretation—not a reproduction, endorsement, or implementation of CryoForge. The decision exercises are synthetic and do not process microscopy data.

01

JUDGMENT

Transfer the control architecture, not the atomic machinery

CryoForge offers a strong reusable pattern for scientific agents: generate bounded proposals, require independent evidence before promotion, make every edit reversible, and stop when evidence is absent or conflicting. Its residue-level actions and atomic validators do not transfer to cellular tomography.

TRANSFER

Agent governance

Proposal–acceptance separation, legal action spaces, independent gates, rollback, trajectory logs, stopping rules, and expert escalation.

REDESIGN

Evidence and actions

Replace atomic metrics with half-map, alignment, reconstruction, topology, continuity, uncertainty, replicate, and biological-context checks.

DO NOT TRANSFER

Atomic-specific logic

Residue edits, sequence registration, bond geometry, rotamers, Ramachandran statistics, clashes, and atomic connectivity.

Claim boundary: the reported CryoForge benchmark outcomes belong to its tested atomic-model trajectories. They do not establish safety, accuracy, or generalization for archaeal specimens, particle processing, tomogram segmentation, or subtomogram averaging.

02

AGENT LOOP

A five-part scientific action contract

The transferable unit is not a language-model prompt. It is a transactional loop in which a proposer is not allowed to certify its own work.

  1. 1

    Diagnose

    Locate a residual problem and record the evidence that triggered review.

  2. 2

    Propose

    Choose one bounded, legal action from a domain-defined action space.

  3. 3

    Gate

    Test the proposal with evidence not reducible to the proposer’s objective.

  4. 4

    Commit or revert

    Promote only a supported derivative; otherwise preserve the previous state.

  5. 5

    Stop or escalate

    End on convergence, conflict, ambiguity, out-of-distribution input, or budget limit.

Proposer ≠ judgeThe optimization path cannot be the sole validation path.

Raw data ≠ editable stateActions create versioned derivatives; raw movies and tilt images remain immutable.

Silence ≠ successEvery run ends with an explicit promote, rollback, stop, or escalate status.

Important distinction: half-map logic transfers most directly to single-particle reconstruction and subtomogram averaging. It is not, by itself, a sufficient validator for whole-cell segmentation, spatial annotation, or biological identity.

04

ATOMIC ONLY

Features that should remain explicitly atomic-model-specific

Representation

Atoms, residues, chains, sequence registration, ligands, and covalent connectivity.

Actions

Backbone or side-chain rebuilding, residue insertion/deletion, sequence reassignment, and local geometric refinement.

Validators

Bond lengths and angles, clashes, rotamers, Ramachandran or CaBLAM statistics, peptide geometry, and atomic map-to-model scores.

Error phenotypes

Mis-traced backbone, register shift, incorrect side chain, broken chain, or locally unsupported atomic interpretation.

Benchmarks

Atomic models paired with maps/half-maps and challenge or deposition-level reference evaluations.

Reported outcomes

CryoForge’s trajectory percentages and “no retained degradation” claim cannot be exported as expected performance for other tasks.

A tomogram membrane is not a peptide chain. A segmentation component is not a residue. A plausible cellular object is not validated by stereochemistry. Reusing those labels would create false precision.

06

DESIGN CONTRACT

A minimum viable agent for archaeal imaging

Start with an orchestration and audit layer around existing tools. Do not begin by training an end-to-end autonomous imaging model.

01

Bound the target

Choose one object and one decision: for example, AMO-particle inclusion, S-layer/membrane boundary repair, or vesicle-component review.

02

Freeze the raw inputs

Hash movies, micrographs, tilt images, metadata, masks, and initial models; all changes occur in versioned derivatives.

03

Enumerate legal actions

Use explicit, parameterized operations with prerequisites, expected outputs, compute limits, and reversible state transitions.

04

Define two metric classes

Use a target metric for desired improvement and guardrail metrics for independence, stability, topology, context, and uncertainty.

05

Write stopping rules first

Specify conflict, oscillation, marginal-gain, out-of-distribution, budget, and expert-review triggers before optimization begins.

06

Log the trajectory

Record input state, diagnosis, proposed action, tool/version/parameters, gate results, decision, rollback pointer, and reviewer note.

Priority archaeal pilots

PILOT A · LOWER RISK

Single-particle branch reviewer

Wrap a purified archaeal S-layer, ribosome, or membrane-complex workflow. The agent proposes a limited retry or branch; half-map and stability gates determine promotion.

PILOT B · HIGH VALUE

Cryo-ET object repair queue

Use VolWeaver- or segmentation-derived objects as proposals. Gate split/merge/boundary repairs using continuity, topology, missing-wedge sensitivity, adjacent-volume context, and reviewer-calibrated uncertainty.

PILOT C · RESEARCH FRONTIER

State-resolved structural trait curator

Promote candidate structural trait units only when geometry, frequency, condition, molecular support, and uncertainty remain linked. Biological interpretation stays downstream of image-level validation.

VolWeaver complement: VolWeaver can supply masks, objects, geometry, and spatial relationships. An evidence-gated agent would govern which repair or relabeling proposal is promoted, rolled back, stopped, or sent to expert review. It should not silently rewrite the reconstructed cellular context.

07

WORKSHOP USE

A 30-minute mixed-background case study

  1. 0–5 min

    Orient

    Explain atomic model building, single-particle cryo-EM, and cellular cryo-ET with one shared vocabulary.

  2. 5–10 min

    Decompose CryoForge

    Identify proposer, evidence gate, transactional state, stopping rule, and escalation route.

  3. 10–18 min

    Run the decision lab

    Small groups decide which synthetic branches to promote, rollback, escalate, or stop.

  4. 18–26 min

    Redesign for an archaeal object

    Each group replaces atomic actions and validators with a workflow-specific action set and evidence gate.

  5. 26–30 min

    Debrief

    Compare where evidence independence failed and name the first expert-review trigger.

Learner output

A one-page agent contract containing: target object, legal actions, target metric, guardrails, rollback state, stopping rules, escalation trigger, and audit fields.
