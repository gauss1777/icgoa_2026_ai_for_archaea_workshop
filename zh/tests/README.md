# 文献演示的状态回归测试说明

以下测试针对**英文原版**。在仓库根目录使用 Node.js 18 或更高版本运行：

```sh
node --test tests/tutorial-state.test.cjs
node --check assets/tutorial.js
```

无需安装依赖包。测试在 Node VM 中运行实际浏览器脚本，使用一个小型 DOM 替身，并读取真实 HTML 中的主题选项、问题、字段、控件 ID 和初始禁用状态。它们检查状态及渲染内容，不检查浏览器布局、原生事件派发、无障碍或跨浏览器行为。

## 预期行为

- 扫描同时保存主题、问题、必选字段与已排序条目。
- 修改主题、问题或必选字段后，清空全部生成结果；重新扫描前禁止生成简报。
- 生成简报时，也检查是否存在未触发事件的输入变化。
- 没有选择必选字段时，阻止扫描并显示原因。
- 重复扫描替换既有输出；重置恢复初始默认值。

测试覆盖三个主题、主题／问题／字段变化、空字段及恢复、重复扫描和生成、未触发事件的编辑、扫描前尝试生成，以及重置。英文原版的检索评分和模拟训练条目保持原有内容。与主题无关的条目仍可能取得正的词汇分数；这与扫描状态是否最新是两个不同问题。

## 真实浏览器的基本检查

运行文档中的本地服务器：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

打开英文页面 `http://127.0.0.1:8000/tutorial-demo.html`。运行一次甲烷主题扫描并生成简报，再切换到氨氧化。确认旧结果、简报和提示词均消失，且重新扫描前“生成证据简报”按钮保持禁用。随后分别修改问题和必选字段，重复检查。取消全部字段后运行扫描，不应生成输出约定或简报。重新勾选一个字段并扫描，再检查重复扫描和重置。

## 中文版的检查边界

中文页面为 `http://127.0.0.1:8000/zh/tutorial-demo.html`。中文版增加固定中文关键词匹配，并翻译界面与模拟条目，因此英文测试不能直接证明中文版的文案或检索行为正确。

本轮翻译未运行测试，也未开展浏览器检查。不能将既有英文测试结果表述为中文版已通过验证。
