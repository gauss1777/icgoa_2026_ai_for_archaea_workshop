# 学习资源

核心练习由本地 HTML、CSS、JavaScript 和人工论文核验组成，不需要 GPU、付费账号、外部模型或编程经验。

## 预备知识

了解基因、蛋白质、基因组及科学论文的基本概念会有帮助。跨领域学习者可先阅读[古菌知识库](../knowledge-base.html)。

## 练习

1. 运行[演示 01](../tutorial-demo.html)。查看模拟来源 ID、命中词和核查提示。修改一个输入，并说明为什么需要重新扫描。
2. 使用[研究阅读导图](../research-updates.html)、[工作表](learner-worksheet.md)和[来源核验 CSV](source-audit-template.csv)，阅读真实的原始研究。
3. 完成[案例 02](../imaging-agent-case-study.html)的四种模拟决策。先写下证据依据，再查看反馈。

研究卡片是阅读导航，不能替代原文。未读的方法或无法获取的材料应明确记录，不要凭记忆补齐。

## 本地访问

在仓库根目录运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8000/zh/`。互动练习不调用外部模型。科学原文链接需要联网；离线学习时，请将依法可获取、可使用的原文段落和工作表保存在本地。

## 可选模型对照

只使用经所在机构批准的服务，并仅提供你有权提交的资料。将模型及版本、提示词、来源记录和输出一起保存。对照人工建立的来源表，逐条核查提取的结论。不得上传保密、未发表或个人资料。

## 适用范围

这些练习用于学习，不是显微数据处理、模型训练或生物学验证。完成工作表不代表科学判断一定正确，也不代表已测得教学效果。详见[文献演示说明](../tutorials/demo-01-literature-triage/README.md)和[成像案例说明](../tutorials/demo-02-evidence-gated-imaging-agent/README.md)。
