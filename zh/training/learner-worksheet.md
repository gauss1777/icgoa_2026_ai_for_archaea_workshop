# 学习工作表：从流畅回答到可核查的结论

核心路径无需外部模型。可使用[学习资源](README.md)，也可独立完成。以下练习用于教学，不构成生物学验证。

## 任务 A：明确模拟证据的身份

1. 打开[演示 01](../tutorial-demo.html)，选择主题并提出适用范围明确的问题。
2. 运行扫描，检查命中词，再生成简报。
3. 为其中一句证据记录对应的模拟来源 ID。
4. 修改问题或某个必选字段，解释为什么不能复用先前扫描。
5. 再次扫描，说明词汇相关性与科学证据支撑有何不同。

提交成果：一份带 `SYN-` 来源标识符的简报，以及一个本演示无法证明的科学结论。字段复选框规定提示词的输出要求，不负责选择性隐藏简报章节。

## 任务 B：核验五篇真实论文

使用[研究网页](../research-updates.html)、[研究卡片](../data/published-study-cards.json)和[CSV 模板](source-audit-template.csv)。阅读原始段落，而不只是卡片。时间有限时，可在小组内分担深入阅读。

| 来源 | 需要核查的问题 |
| --- | --- |
| R01 / archaeasins（古菌来源候选抗菌肽） | 实验命中率的统计分母是什么？能否外推到全部预测候选？ |
| R02 / 古菌组蛋白 | 哪些结果来自预测或模拟，哪些是在活细胞中观察到的？ |
| R03 / Evo 2 | 古菌基因必需性评测位于何处？它不能证明哪些基因组设计结论？ |
| R04 / Methanoperedens 元件 | 哪些证据支持元件与宿主的关联？什么证据才能确认生理效应？ |
| R05 / 黏附素样蛋白 | 长度筛选、注释参照、评测集划分和软件可用性如何限制解释？ |

每行填写标识符与版本、研究对象背景、原文定位信息、实际阅读范围、证据支持的结论、证据对象、不确定性、容易作出的无依据外推，以及下一步核查。诚实标注访问缺口和未读章节。

提交成果：五条适用范围明确的核验记录，以及对一篇论文主要局限的简短讨论。资料库只确认年份时，不要补造精确发表日期。

## 任务 C：为操作设置证据条件

打开[案例 02](../imaging-agent-case-study.html)。判断每个场景应采用候选分支、回退、转交专家复核还是停止。在查看既有解释前，先写下基于证据的理由。

为一个范围明确的古菌成像对象设计操作约定：

| 约定字段 | 你的记录 |
| --- | --- |
| 生物学问题与目标对象 | |
| 对有版本记录的衍生数据提出的操作 | |
| 证据对象及其来源记录 | |
| 验证器及其与提案方的独立性 | |
| 针对此项结论的采用条件 | |
| 回退检查点 | |
| 停止条件或资源上限 | |
| 转交专家复核的触发条件 | |
| 本工作流不得作出的结论 | |

提交成果：一份不会仅凭外观就接受分子身份或功能判断的约定。基准评分提高，并不自动构成生物学结论。

## 任务 D：设计具有判别力的核查

从任务 B 或 C 中选择一个无证据支持的外推。提出两种相互竞争的解释，以及一个能够区分它们的观察。说明为什么该观察比另一段流畅的模型回答更能直接回答问题。

提交成果：一个经过收敛的结论句、两种竞争解释和下一步核查计划。不要求执行实验。

## 可选任务：与经批准的模型对照

记录模型与版本、提示词，以及依法有权提供的原文段落。要求模型输出与人工核验相同的字段。标记虚构来源、丢失的统计分母、无依据的因果表述和遗漏的不确定性。保留人工决定及其理由。不要上传非公开资料。
