## 会议背景

2026 年国际古菌地球组学大会（International Conference on Geo-Omics of Archaea 2026，ICGOA 2026）计划于 2026 年 12 月 1至4 日在中国广州的中山大学举行，主题为“迈向跨域视角”（Toward A Cross-Domain Perspective）。

## 你将练习什么

- 先明确古菌生物学问题，再选择工具。
- 区分词汇层面的检索相关性、模型解释与生物学证据支撑。
- 保留来源标识符、原文定位信息和未解决的不确定性。
- 核查真实论文的统计分母、验证对象及结论的适用范围。
- 为具体结论设计采用、回退、转交专家复核和停止的条件。
- 说明哪些人工复核或生物学测量仍不可省略。

1. 阅读[古菌入门知识库](knowledge-base.html)。

5. 最终形成可核查的来源表和适用范围明确的证据审核约定，而不是声称获得了新的生物学发现。

## 本地与离线使用

在**仓库根目录**内运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8000/zh/`。使用 `Ctrl+C` 停止服务器。

两个互动练习均使用本地 HTML、CSS 和 JavaScript，不需要 API 密钥、安装依赖包或下载模型。科学原文链接需要联网。离线使用时，请在本地保留仓库和来源核验表，由组织者提前准备依法可获取、可使用的原文段落。不要假设会场一定能访问出版社网页或外部录像。

## 这些演示是什么，又不是什么

**演示 01：** 对 `SYN-S1` 至 `SYN-S3` 进行透明的关键词排序，随后生成固定结构的教学简报和限定来源的模型提示词。修改主题、问题或必选字段后，先前扫描立即失效。字段选择规定提示词要求输出哪些字段，并不会选择性隐藏固定简报中的章节。中文版增加预先列出的中文关键词匹配；它不是训练好的语言模型、科学搜索引擎、中文语义检索系统或经过验证的“无匹配”检测器。

**案例 02：** 用于练习成像智能体证据门控的概念性案例，不处理显微数据，也不复现任何科学智能体实现。

**真实论文衔接：** 以人工证据核验为核心，可选用经所在机构批准的模型进行对照。已发表研究卡片不替换浏览器中的模拟条目，也不是模型生成的科研结果。核心路径不需要 GPU 或外部模型。

## 负责任地使用

- 不向外部服务上传保密、未发表、个人或访问受限的资料。
- 区分预测序列、预测折叠、结构域标签、转录本、图像对象与实测表型。
- 每条结论都应附上来源版本、实际阅读范围和原文定位信息。
- 区分相互关联的计算验证结果与独立的生物学观察。
- 保持原始成像数据不变，只在有版本记录的衍生数据上操作。
- 报告不确定性、相反结果及数据集和标签的局限。
- 在领域专家参与下复核分类、功能、环境背景和因果表述。
- 再分发资料前，检查来源授权和所在机构的适用政策。
