# 入门指南

## 需要准备什么

使用现代浏览器即可完成两个互动练习。不需要 API 密钥、模型账号、安装依赖包或 GPU。原始来源链接需要联网。

本仓库是独立教学资源。会议日期、报名和会场信息请查阅 [ICGOA 2026 官方网站](https://www.icgoa2026.com/)。

## 选择起点

1. 不熟悉古菌生物学时，先阅读[知识库](../knowledge-base.html)。
2. 打开[演示 01](../tutorial-demo.html)，查看透明检索工作流。
3. 配合[研究证据](Research-Evidence.md)和[来源核验清单](Source-Audit-Checklist.md)，阅读一篇真实论文。
4. 打开[演示 02](../imaging-agent-case-study.html)，解释一项适用范围明确的成像决策。

[学习工作表](../training/learner-worksheet.md)提供练习问题，[空白 CSV](../training/source-audit-template.csv)提供可复用的核验字段。

## 运行本地副本

克隆或下载公开来源仓库。已安装 Python 3 时，在仓库根目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

在浏览器中打开 `http://127.0.0.1:8000/zh/`。按 `Ctrl+C` 停止服务器。

练习在本地运行，但下载仓库并不会让外部论文和数据库自动离线可用。

## 什么样的成果才有用

形成表述具体的问题、带来源链接的证据表、适用范围明确的解释和人工核查计划。仅有一段流畅摘要并不是目标。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| “生成证据简报”按钮不可用 | 设置主题、问题和至少一个必选字段后，运行扫描 |
| 编辑输入后旧结果被清空 | 属于预期行为：旧扫描已经不能代表当前输入 |
| 未选择任何字段 | 至少选择一个字段，再次扫描 |
| 表格宽于手机屏幕 | 在表格自身的区域内横向滚动 |
| 原始论文无法访问 | 记录访问限制，不要暗示已阅读全文 |
| 仍显示旧布局 | 先执行不使用缓存的重新加载，再判断是否为布局问题 |
