# 古菌知识库

## 古菌是什么

古菌在演化上与细菌不同。其细胞没有由膜包裹的细胞核，但部分信息处理机制与真核生物系统有深层相似性。古菌不能简单理解为生活在极端环境中的细菌。

生物学概览见[完整入门知识库](../knowledge-base.html)。

## 避免三种误解

| 误解 | 更准确的认识 |
| --- | --- |
| 所有古菌都是嗜极生物 | 古菌也存在于海洋、土壤、沉积物、微生物组和工程化系统 |
| 检出基因就证明有活性 | 基因支持基因组潜力；表达、蛋白和实测速率回答不同问题 |
| 预测结构就证明了功能 | 模型提供可能结构的线索，不等于完整生理验证 |

## 细胞生物学

典型古菌膜脂含有醚键连接的异戊二烯链。部分谱系具有可跨膜的四醚脂。许多古菌具有蛋白质 S 层；细菌型肽聚糖不是古菌细胞壁的组成成分。不同谱系的细胞分裂和包被结构各不相同。

## 代谢与生态

产甲烷、甲烷厌氧氧化、氨氧化、硫转化、氢代谢及多种碳利用策略，均是重要的古菌研究主题。证据支持哪种过程，取决于谱系、环境和证据本身。

解释环境结果时，应始终保留采样深度、化学条件、采集方法、微生物伙伴和空间背景。

## 证据层次

| 证据 | 可回答的问题 | 主要局限 |
| --- | --- | --- |
| 标记基因扩增子 | 检出了哪些目标谱系？ | 引物偏倚，功能分辨能力有限 |
| 宏基因组 | 存在哪些基因和重构基因组？ | 组装、分箱、污染及不完整性 |
| 宏转录组 | 采样时检出了哪些 RNA？ | 表达不是过程速率的直接测量 |
| 蛋白质组 | 检出了哪些蛋白？ | 受提取方法及参考数据库影响 |
| 稳定同位素或速率测量 | 在所测条件下，哪些转化过程获得支持？ | 模型假设、对照及途径重叠 |
| 培养 | 在受控条件下观察到哪些生理特性？ | 实验室条件可能不同于自然环境 |
| 显微成像 | 观察到哪些细胞、结构或空间关系？ | 身份判定、样品制备和取样的局限 |

## 入门术语

| 术语 | 含义 |
| --- | --- |
| AOA | 氨氧化古菌 |
| ANME | 厌氧甲烷氧化古菌 |
| MAG | 宏基因组组装基因组 |
| mcrA | 甲基辅酶 M 还原酶及相关甲烷代谢的标记基因 |
| S 层 | 由蛋白或糖蛋白亚基形成的细胞表面层 |
| 互营 | 通过交换产物或耦合反应形成的代谢协作 |
