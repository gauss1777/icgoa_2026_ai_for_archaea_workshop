# 案例 02：古菌成像中的证据门控智能体

## 目标

借助 2026 年 bioRxiv 预印本 *CryoForge: A Self-Correcting Agent for Cryo-EM Model Building That Learns When to Act and When to Stop*（面向冷冻电镜模型构建、能够自我纠正并判断何时行动与停止的智能体），区分可借鉴的科学智能体架构与原子模型构建专用组件。

[打开案例 02](../../imaging-agent-case-study.html)

## 核心判断

模拟练习展示基于证据的一般决策方式，不提供可直接使用的古菌成像智能体，也不复现 CryoForge 方法。

可借鉴的组件包括：

- 将“提出修正方案”与“接受修正方案”分开。
- 依据领域约束规定允许的操作集合。
- 设置不能被提案方的优化目标替代的证据审核关口。
- 以可回退的方式接受候选结果。
- 明确停止和转交专家复核的状态。
- 保存运行轨迹的来源记录，并按条件分层评测。

仍属于原子模型构建专用的组件包括：

- 残基、片段、链及序列配准层面的错误类型。
- 主链与侧链重建操作。
- 键几何、侧链构象、拉氏图、原子碰撞、肽链连通性等原子级验证器。
- 原子级密度图与模型匹配指标，以及模型挑战的参考集合。

## 学习目标

- 解释为什么不能只用智能体自己优化的目标来验证它提出的方案。
- 将同一治理闭环映射到单颗粒冷冻电镜和细胞冷冻电子断层成像，而不照搬不适用的指标。
- 在采用候选分支、回退、停止和转交专家复核之间作出选择。
- 说明范围明确的决策背后的证据、不确定性和缺失观察。
- 区分图像层面的证据、生物学身份判定与机制解释。

## 迁移对照

| 组件 | 单颗粒冷冻电镜（cryo-EM） | 细胞冷冻电子断层成像（cryo-ET） | 适用边界 |
| --- | --- | --- | --- |
| 问题诊断 | 不稳定的粒子、类别、取向、CTF 或精修分支 | 对齐失败、边界不连续、不合理对象、不确定的粒子拾取 | 异常标记只触发复核，不等于证明有错 |
| 操作 | 重试范围受限的分支；调整衍生子集或掩膜 | 重试衍生重构；拆分／合并标签；修正拾取结果 | 绝不覆盖原始电影帧或倾转图像 |
| 证据门控 | 半图表现、FSC／局部分辨率、取向覆盖及不同随机种子／子集下的稳定性 | 对齐／重投影残差、留出视图或体数据、连续性、拓扑、缺失楔敏感性、重复样本及专家复核子集 | 半图本身不能验证整细胞分割或生物学身份 |
| 回退 | 保留先前已验证的分支 | 保留先前状态及相互竞争的假说 | 可逆性必须落实为操作机制，不能只停留在声明 |
| 停止／转交复核 | 无可重复增益、约束指标恶化、振荡或达到计算上限 | 采集限制导致的歧义、拓扑冲突、不稳定、分布外样品或达到标注上限 | 歧义是合理的终止状态 |

## 决策练习

互动页面包含四种模拟情境：

1. 单颗粒分支的名义指标更好，却缺乏独立支持。
2. 范围受限的单颗粒精修获得可重复增益，约束指标保持稳定。
3. 膜与 S 层边界在缺失楔方向上仍难以区分。
4. 冷冻电子断层成像的拆分／合并循环已经振荡，并达到计算限制。

选择**采用候选分支**、**回退**、**转交专家复核**或**停止**，再阅读证据审核的理由。

## 基准标签与独立证据

[模体标注研究](https://www.nature.com/articles/s41592-025-02800-5)是可借鉴的基准资源，不是古菌细胞验证。作者讨论了标签不完整和可能出现假阳性的问题。应记录参考标签的不确定性；针对人工整理参照得到的分数，不能证明分子身份、迁移到古菌的适用性或生理功能。

对每项拟议操作，明确证据对象、验证器，以及验证证据是否真正独立于提案方。相关计算方法间的一致性可能有价值，但不会因此成为新的生物学观察。采用候选结果始终只针对范围明确的结论。
