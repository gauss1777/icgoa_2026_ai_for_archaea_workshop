# 教程演示 01：以证据为先的古菌文献筛选

## 目标

练习一个透明的工作流：从古菌研究问题出发，形成规模小、便于复核的证据简报。

[打开教程演示 01](../../tutorial-demo.html)

## 学习目标

- 提出适用范围明确的生物学问题。
- 明确展示用于检索的概念。
- 阅读支持语句，而不是仅凭相关性排序作判断。
- 让来源 ID 始终与提取的结论相连。
- 区分检索相关性与科学证据支撑。
- 准备人工核查清单。

## 训练数据

演示包含三个**模拟条目**：

- `SYN-S1`：缺氧沉积物中的甲烷转化。
- `SYN-S2`：贫营养水体中的氨氧化古菌。
- `SYN-S3`：高盐富集培养体系中的古菌病毒与宿主相互作用。

它们是教学对象，不是真实论文，特意不提供 DOI、作者或期刊元数据。

## 工作流

### 第一步：提出问题

选择主题并编辑研究问题，决定哪些证据字段必须输出。

### 第二步：检索

运行证据扫描。浏览器结合明确列出的主题词与从问题中提取的关键词，对每条训练记录透明评分。中文版中文关键词来自固定词表，英文按字母数字词元处理；不进行语义理解。

### 第三步：检查

逐条检查候选记录的命中词、环境背景、一句支持语句和核查提示。

分数高表示词汇相关性较高，不表示生物学结论为真。

### 第四步：结构化整理

生成证据简报。输出包含带来源标签的证据、适用范围明确的解释，以及人工复核清单。

### 第五步：准备供模型使用的提示词

检查生成的提示词。它将模型限制在提供的条目内，明确禁止编造来源和过度解释。

## 无需 API 密钥

演示完全在浏览器内运行，不将数据发送给外部服务。[评分脚本](../../assets/tutorial.js)有意保持可读。评分形式为“主题加分 + 命中词数量”，不同语言版本的命中词和分数不保证逐条一致。

## 拓展练习

使用[准备好的五篇论文衔接练习](../../training/learner-worksheet.md)和[来源核验 CSV](../../training/source-audit-template.csv)，另行开展真实文献练习。浏览器演示保留三个模拟条目，不能悄悄将它们当作已发表研究。

对每篇真实论文记录：

- DOI、PMID 或其他稳定标识符。
- 获取日期。
- 研究对象名称及分类来源。
- 环境和采样设计。
- 支持结论的原文语句。
- 证据层次。
- 不确定性或相反结果。

然后将人工建立的简报与经批准的模型辅助简报进行比较，逐项核查差异。

## 负责任使用的检查点

不要将保密、未发表、个人或访问受限的资料上传给外部模型。连接任何 API 前，检查所在机构与项目的政策。

## 扫描状态边界（2026 年 10 月补丁）

1. 选择主题和问题，并保留至少一个必选字段。
2. 运行扫描，检查已排序的模拟条目。
3. 简报只使用该次扫描保存的主题、问题和字段快照。
4. 修改上述任一输入后，旧扫描、简报和提示词失效；再次生成前必须重新扫描。
5. 重置恢复预设输入，并清空先前扫描。

没有选择字段时，扫描被阻止并显示原因。生成简报时，还会检查没有触发通常事件的输入变化，避免明知输入已改却仍复用旧扫描。这保护的是界面状态一致性，不是科学准确性。

必选字段复选框属于**提示词要求**。简报使用固定教学模板，减少字段并不会选择性删掉简报章节。主题加分和关键词匹配不是经过验证的“无匹配”检测器。

用户提供的补丁在[测试文件夹](../../tests/README.md)中加入了 16 个最小化 DOM 回归案例。这些检查不能替代真实浏览器、布局、键盘或无障碍评估。教学资料升级时未重新运行；本轮中文翻译也未运行这些测试。

## 准备好的真实论文衔接

核心集合为[研究卡片 JSON](../../data/published-study-cards.json)中的 R01至R05：archaeasins（古菌来源候选抗菌肽）、组蛋白、Evo 2、Methanoperedens 染色体外元件及甲烷杆菌目黏附素样蛋白。请打开原始来源。卡片仅用于阅读导航和转述，不能替代方法或图表。

每行写明一项有证据支持的结论、对应的证据对象、一个容易作出的无依据外推，以及下一步需要的观察。[工作表](../../training/learner-worksheet.md)规定提交成果。出版社页面无法访问时，应记录访问缺口，不要编造支持段落。

可选用经批准的模型，对一段依法有权提供的短原文提出结构化提取建议。与人工核验对照，记录模型、版本和提示词，拒绝无依据的结论。本仓库不实现模型调用，也不要求使用模型。
