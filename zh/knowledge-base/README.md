# 古菌入门知识库

为来自微生物学、基因组学、地球化学、数据科学或人工智能领域的学习者，提供简明的古菌研究基础。

这是一张入门导图。复用任何科学结论前，请核查最新分类、数据库版本和原始文献。

## 1. 古菌是什么

古菌是细胞生命的主要域之一。其细胞属于原核型组织方式，但在演化上与细菌不同。古菌的信息处理系统中，一些组成部分与真核生物的转录、复制机制具有深层联系。

**常见误解：** 并非所有古菌都是嗜极生物。古菌也广泛存在于海洋、土壤、沉积物、宿主相关系统、工程化环境和其他非极端生境。

## 2. 细胞生物学

- **细胞膜：** 典型古菌膜脂以醚键将异戊二烯链连接到甘油-1-磷酸上。部分谱系具有可跨越整个膜厚度的四醚脂。
- **细胞包被：** 许多古菌具有蛋白质构成的 S 层。古菌不含细菌型肽聚糖，部分产甲烷古菌具有假肽聚糖。
- **基因表达：** 古菌转录系统与真核生物系统存在重要相似性。
- **细胞分裂：** 不同谱系采用不同机制，包括 ESCRT 相关系统和 FtsZ 系统。

## 3. 主要代谢方式

### 产甲烷作用

产甲烷古菌参与生物甲烷的产生。不同途径可利用二氧化碳、乙酸、甲基化合物等底物。甲基辅酶 M 还原酶是产甲烷及相关甲烷代谢的关键酶。

### 甲烷厌氧氧化

若干古菌类群能够在无氧条件下氧化甲烷，通常涉及微生物伙伴，以及与环境地球化学条件相联系的电子受体。

### 氨氧化

氨氧化古菌广泛分布于海洋和陆地环境，在低氨条件下也可发挥重要作用。

### 其他策略

古菌还具有多样的碳固定途径、异养代谢、硫和氢代谢，以及基于视黄醛的光驱动离子泵。

## 4. 生态学核查清单

解释环境研究结果前：

1. 记录生境、深度、化学条件、采样时间和采集方法。
2. 区分相对丰度、绝对丰度与活性。
3. 区分基因组潜力与 RNA、蛋白、代谢物、同位素或速率证据。
4. 考虑微生物伙伴、病毒及空间组织。
5. 说明证据来自分离培养物、富集培养物、基因组还是群落。

## 5. 常见证据层次

| 证据层次 | 能回答的问题 | 主要注意事项 |
| --- | --- | --- |
| 扩增子 | 目标标记对应的群落组成 | 引物偏倚，功能推断范围有限 |
| 宏基因组 | 群落基因与重构基因组 | 组装、分箱、污染和不完整性 |
| 宏转录组 | 采样时的 RNA 表达 | 表达本身不能独立确定过程速率 |
| 蛋白质组 | 检测到的蛋白及通路证据 | 受提取方法和参考数据库影响 |
| 稳定同位素 | 来源、转化与速率 | 模型假设及不同途径的重叠 |
| 培养 | 受控条件下的生理特性 | 实验室条件未必代表自然生境 |
| 显微成像 | 结构、定位与相互作用 | 身份识别和取样的局限 |

## 6. AI 在古菌研究中的用途

### 可发挥作用的环节

- 扩展检索词，进行文献初筛。
- 从指定来源中提取结构化信息。
- 排定注释优先级，复核异常。
- 起草代码并整理文档。
- 梳理相互竞争的假说。

### 高风险失误

- 编造引文或标识符。
- 使用过时分类。
- 对基因功能作出过于确定的判断。
- 丢失环境背景。
- 将相关性写成因果关系。
- 将基因组潜力写成已经证实的活性。

### 最低证据要求

任何科学判断离开 AI 辅助工作流前，都应具备：

1. 来源标识符。
2. 支持该判断的原文语句或数据对象。
3. 不确定性说明。
4. 明确的人工核查步骤。

## 7. 入门术语

- **AOA：** 氨氧化古菌。
- **ANME：** 厌氧甲烷氧化古菌。
- **MAG：** 宏基因组组装基因组。
- **mcrA：** 甲基辅酶 M 还原酶的常用标记基因。
- **S 层：** 由蛋白或糖蛋白亚基组成的细胞表面层。
- **互营（Syntrophy）：** 通过耦合反应或交换产物形成的代谢协作关系。
- **四醚脂：** 在若干古菌谱系和环境中存在、可跨越整个膜厚度的膜脂。
